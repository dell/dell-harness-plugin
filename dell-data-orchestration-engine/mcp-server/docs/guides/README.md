# Workflow guides

Conversational walkthroughs of the DOE MCP server, used by the evaluation harness
(see [`../eval.md`](../eval.md)) as the source of its golden traces.

They cover the complete server, across every profile. The Dell plugin starts the focused
`plugin-v1` profile, and its workflow skills describe what that profile can do; where a guide
uses a tool the plugin profile does not expose, follow the plugin skill instead.
